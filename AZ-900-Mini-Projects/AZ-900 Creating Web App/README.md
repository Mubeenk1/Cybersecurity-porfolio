# 🌐 AZ-900 Mini Project – Creating a Web App in Azure

## 📘 Overview

In this mini project, I created a basic **Web App using Azure App Services**, part of my AZ-900 learning journey. The purpose was to understand how to deploy a scalable, cloud-hosted web application without managing underlying infrastructure.

---

## 🧱 Azure App Services (PaaS)

Azure App Service is a **Platform as a Service (PaaS)** offering. It enables you to build and host many types of web-based solutions without managing hardware or infrastructure.

### ✅ Key Features:
- Supports multiple programming languages and containerized deployments
- Auto-scaling and built-in load balancing
- High availability and traffic management through Azure Traffic Manager
- HTTP-based service for hosting web apps, RESTful APIs, and mobile backends

### 📦 Types of App Services:
- **Web Apps** (which we deployed in this lab)
- **API Apps**
- **WebJobs**
- **Mobile Apps**

This makes it a versatile choice for developers who need performance, reliability, and speed of deployment.

---

## 🔨 What I Did

1. Accessed **App Services** in the Azure Portal and selected **Web App**.
2. Created a new **Resource Group** and gave the Web App a unique name.
3. Selected runtime stack and **region (Australia East)** for optimal latency.
4. Deployed the app using default configurations.
5. Launched the site using the provided URL and confirmed successful deployment.

---

## 🧠 What I Learned

- How to deploy a **PaaS web application** using Azure App Services
- The role of **resource groups**, **service plans**, and **regions**
- The simplicity of launching web apps in minutes without touching infrastructure
- How Azure provides scaling, load balancing, and availability out of the box
