## 🛡️ What Is a Firewall?

A **firewall** is a network security system that monitors and controls network traffic using a set of security rules. Its purpose is to permit or block data packets based on a defined set of rules to protect systems from unauthorized access, malware, or cyberattacks.

---

## 🧱 Types of Firewalls

1. **Network-Based Firewalls**  
   - Placed between two or more networks (e.g., office LAN and external internet)  
   - Managed remotely from a small number of secure hosts  
   - Commonly used to **limit access to allowed services**  
   - 🛠️ Examples: Cisco ASA, Juniper, Palo Alto Networks

2. **Host-Based Firewalls**  
   - Installed on individual hosts or endpoints  
   - Managed via GUI or local scripting (e.g., iptables, PowerShell)  
   - 🖥️ Examples: Microsoft Defender Firewall (Windows), iptables (Linux)  
   - Most antivirus software includes a built-in host-based firewall

3. **Packet-Filtering Firewalls**  
   - Basic firewalls that work at the network layer  
   - Use a **top-down rule list** to allow or deny traffic  
   - No awareness of connection state

4. **Stateful Firewalls**  
   - Track the **state** of connections (e.g., new, established, related)  
   - Automatically allow response traffic when outbound rules are defined  
   - More secure and intelligent than basic packet filters

5. **Application-Layer Firewalls**  
   - Operate at the **application layer (Layer 7)**  
   - Filter traffic based on applications (e.g., HTTP, FTP, DNS)

6. **Next-Generation Firewalls (NGFW)**  
   - Combine **stateful filtering + application-level controls**  
   - Include **DPI (Deep Packet Inspection)**, **IPS/IDS**, **malware protection**, and more  
   - Provide visibility into application behavior and user identity

7. **MAC Layer Firewalls**  
   - Work at the **MAC sublayer** of the data link layer  
   - Control traffic based on **device MAC addresses**

## 🔧 About IPTables

On Linux systems, **iptables** is a host-based firewall utility used to create rules for filtering network traffic. It allows system administrators to define detailed packet filtering and NAT rules.

### 📌 IPTables Policy Chains:
- `INPUT`: Controls packets **destined for the local system**
- `OUTPUT`: Controls packets **generated by the local system**
- `FORWARD`: Controls packets **passing through the system (e.g., a router)**
