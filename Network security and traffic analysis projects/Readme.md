# 🛡️ Network Security and Traffic Analysis Projects

This folder contains my hands-on projects focused on network traffic analysis using various tools. The aim is to build strong practical skills in detecting and investigating network-based threats.

## 🔧 Tools Used

- **Wireshark**
- **TShark**
- **Zeek**
- **Suricata**
- **Snort**
- **NetworkMiner**
- **Brim**

## 🎯 Objective

To learn and apply network analysis techniques using different tools by:
- Capturing and analyzing network traffic
- Investigating malicious behavior (e.g., phishing, DNS tunneling)
- Extracting and documenting Indicators of Compromise (IOCs)
- Creating and tuning detection rules

## 📈 Outcome

These projects demonstrate my ability to use multiple tools for network threat detection and analysis. Each case reflects my growth as a cybersecurity analyst and helps me better understand real-world attack patterns and defense strategies.
