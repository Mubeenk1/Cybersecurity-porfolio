This repository contains documentation and reports from hands-on lab exercises conducted as part of my **Ethical Hacking and Security Governance** university subject.

## 🎯 Purpose

The objective of these labs is to develop a practical understanding of offensive security techniques in a controlled, sandboxed environment. By learning to think from an attacker's perspective, I aim to build a deeper, more intuitive knowledge of system vulnerabilities and, most importantly, the defensive strategies required to mitigate them.

## ⚠️ Important Note

*   **All activities were performed in an isolated virtual lab environment.**
*   **These techniques are for educational purposes only.**
*   **Understanding these attacks is the first step toward building effective defenses and fostering a strong security governance mindset.**
